How publishing actually works here. This page can't call YouTube/X/Instagram directly — those APIs block browser requests or require signed OAuth requests, which need a server. The /server folder in this project is that server: run it locally (or deploy it free on Render/Railway), drop your API keys in below, and posts you publish from here go through it for real. If a platform's keys are missing, SoLink will stop you and tell you exactly what's missing instead of pretending it worked.
